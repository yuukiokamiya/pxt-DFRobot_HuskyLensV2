# huskylens2 拡張 ― ファームウェア 1.4.2 対応版（非公式）

DFRobot の MakeCode 拡張 [pxt-DFRobot_HuskyLensV2](https://github.com/DFRobot/pxt-DFRobot_HuskyLensV2) v1.1.7 を、
HUSKYLENS 2 ファームウェア 1.4.2（通信プロトコル V0.4）で動くように直したものです。

**このバージョンは新しいファームウェア（1.4.2 以降）専用です。** 1.2.1 などの古いファームウェアでは、名前や文字の読み取りがずれて動きません。
DFRobot が公式の拡張を更新したら、そちらに戻してください。

## 何を直したか
プロトコル V0.4（2026-10-29）で、データ部分の固定ヘッダーが **10 バイト → 14 バイト** になりました（オフセット 10〜13 に信頼度 conf が追加）。
これに合わせて、Arduino ライブラリ [DFRobot_HuskylensV2 v1.4.2](https://github.com/DFRobot/DFRobot_HuskylensV2/releases/tag/v1.4.2) と同じデータの並びにしました。

| 場所 | 変更 |
|---|---|
| 認識結果（名前・内容） | 名前の長さをオフセット 14 から読む |
| 返ってくる文字列（写真・スクリーンショットのファイル名） | オフセット 14 から、長さ付きの文字列として読む |
| 接続確認・アルゴリズム切り替え・撮影 | 送るデータを 14 バイトにする |
| 枠を指定して学習 | 14 バイト（x, y, w, h + 予備 4 バイト） |
| 画面に文字表示 | 色をオフセット 10 に、文字をオフセット 14 から（長さ付き） |
| 枠の描画 | 色をオフセット 10 に（全体 14 バイト） |
| 音声再生・IDへの名前付け | 14 バイトのあとに長さ付きの文字列 |
| 中央を学習・学習を消す | データなしで送る（Arduino ライブラリと同じ） |
| 自作モデルの番号 | 20〜22 → 25〜27（新ファームでは 20 が深度カメラ、21・22 が自動運転） |
| 信頼度 | 内部で読めるようにした（`conf`、ブロックはまだない） |

ブロックの名前・形は変えていないので、今までのプログラムはそのまま使えます。

## v1.3.0 で追加した機能（Arduino ライブラリ v1.4.2 から移植）

### 複数のアルゴリズムの同時実行
「algorithm switch」の所に、次のブロックを追加した。

| ブロック | 内容 |
|---|---|
| run algorithms together A and B | 2つのアルゴリズムを同時に動かす |
| run algorithms together A and B and C | 3つのアルゴリズムを同時に動かす（最大3つ） |
| set run ratio of combined algorithms a : b (: c) | それぞれを動かす割合（0 = 止める） |

同時に動かしたあとは、それぞれのアルゴリズムの「get ... result」ブロックで結果を取り、いつもの値のブロックで読む。
そのために、結果の保存場所をアルゴリズムごとに分けた（今までは全アルゴリズムで1か所だった）。

### 関節などの座標（キーポイント）
| カテゴリ | ブロック | 点 |
|---|---|---|
| hand recognition | hand nearest to center keypoint [点] [x/y] / hand No.n keypoint [点] [x/y] | 手首、親指〜小指の関節と指先（21点） |
| pose recognition | pose nearest to center keypoint [点] [x/y] / pose No.n keypoint [点] [x/y] | 鼻、目、耳、肩、ひじ、手首、腰、ひざ、足首（17点） |
| face recognition | face nearest to center keypoint [点] [x/y] / face No.n keypoint [点] [x/y] | 両目、鼻、口の両端（5点） |

先にそのアルゴリズムの「get ... result」を呼ぶ。対象や点がないときは -1 を返す。

### その他
- 受け取り用の領域を 128 → 512 バイトにした（関節のデータは1回分が大きいため）。
- 一度に保存する結果を 6 → 10 個にした（Arduino の大きいメモリ向けの設定と同じ）。
- micro:bit **V2** 向け。

## 使い方
1. この内容を GitHub のリポジトリ（DFRobot のリポジトリのフォーク）に置く。
2. MakeCode のプロジェクトで、公式の huskylens2 拡張を入れている場合は削除する
   （JavaScript 表示 → 「エクスプローラー」→ huskylens2 のゴミ箱）。
3. 「拡張機能」の検索欄に、フォークの URL（例: `https://github.com/<アカウント>/pxt-DFRobot_HuskyLensV2`）を入れて追加する。
